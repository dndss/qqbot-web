# QQ Bot 消息工作台

基于仓库内置 `qq-official-bot` SDK 的轻量 Web 消息工作台。它使用 QQ 官方机器人协议，不登录个人 QQ。

## 功能

- WebSocket 连接 QQ 官方网关
- 接收群聊和 C2C 私聊消息
- 类 QQ 的会话列表与聊天界面
- 向已有会话发送普通文本、Raw Markdown、图片、视频、语音和普通文件；普通消息支持文本与一张图片组合发送
- 收到的文本（包括已保存的历史消息）和明确标记为 Markdown 的发送消息在前端渲染标题、粗斜体、列表、引用、代码块、表格、链接和图片；连续的文本和 @ 在同一 Markdown 上下文渲染，保留 @ 名称。普通模式发送的文本保持原样，复制整条消息仍保留源码；不修改 SDK 或历史存储。
- 兼容 QQ 的 `![#宽 #高](url)`、`![说明 #宽px #高px](url)` 图片尺寸和 `<qqbot-at-user id="openid" />`。`mqqapi://aio/inlinecmd?command=...` 菜单显示为按钮，点击只将解码后的命令插入输入框光标位置，不自动发送、不唤起 QQ；输入长度超限时提示。
- Markdown 使用本地依赖 `markdown-it`，无需 CDN；禁用原始 HTML，图片和普通链接仅允许 HTTP/HTTPS（含相对地址），加载失败的图片显示提示。仅上述 QQ 菜单格式作为本地输入操作处理，其他自定义协议不开放。
- 媒体消息支持公网 HTTP/HTTPS 地址或直接选择本地文件；本地上传完成或失败后自动清理临时文件
- 右键消息可撤回 Bot 消息、引用回复或不引用回复；被动回复使用顺序 `msg_seq`
- 当前消息正文始终显示；能从当前会话全部已保存历史中精确匹配原消息的引用显示发送者和正文，点击直接定位，未加载的历史会自动补齐；无法溯源的引用默认折叠，点击“引用消息”展开或收起快照
- 接收 `message_type=103` 时由 SDK 解析引用快照；`TMP_...` 或不匹配的引用索引只展示内容，不猜测原消息身份
- 消息右键菜单支持复制选中文字或整条消息正文
- 消息右键菜单及手机“…”菜单支持“查看消息数据”：用弹窗查看已加载历史消息记录的格式化 JSON 并复制；排除查询附带的引用摘要和临时上传状态。消息更新时同步显示，切换账号或会话时关闭；不保存或还原 QQ 原始网关包。
- 视频点击下载时由 Web 服务端流式中转，保留原文件名和后缀；缺少后缀时根据视频格式识别，不缓存完整视频
- 音频与视频共用服务端流式下载；官方 `voice` 附件显示为音频，保留 AMR 原文件名，并在提供 `voice_wav_url` 时单独显示“下载 WAV”，不在本地转码
- 提供官方 WAV 副本的语音支持在线播放、暂停和拖动进度；默认不预加载或自动播放，同一时间只播放一条，切换会话、账号或撤回消息时停止播放并清理请求
- 手机和平板只通过主动点击消息旁的“…”打开操作菜单；长按消息或头像不弹出自定义右键菜单，保留系统文字选择，点击菜单时保留选区
- 右键群成员头像可将 `<qqbot-at-user id="openid" />` 直接填入输入框，并自动切换、锁定为 Markdown；删除标签后自动解除锁定
- 插入有效 @ 后输入区会自动切换并锁定为 Markdown；Markdown 图片可使用 `![#宽 #高](url)` 语法
- 右键群成员头像可按预设或自定义时长禁言，也可解除禁言
- 结构化渲染文本、图片、QQ 系统表情、@、回复及媒体文件链接
- 结构化渲染收到的合并聊天记录；其中图片和动图自动缓存，旧记录在打开会话时懒解析最近 200 条
- 将普通图片和图片形式的表情包缓存到每个 Bot 的本地媒体目录，官方链接失效后仍可查看
- 首次收到群消息时通过 `/v2/groups/{group_openid}/info` 获取并缓存群名称、人数、简介、分类和标签
- 首次收到群消息时缓存机器人群内身份、入群时间、主动消息权限和接收设置，并可在群详情手动刷新
- 消息发送者名字旁显示 `BOT`、`管理员`、`群主`徽标；用户角色从新收到的 SDK 事件权限中保存
- 保存多个 Bot 账号并在 Web 中切换；同一时间只连接一个 Bot，每个账号使用独立聊天记录文件
- 使用 `thirdqq.qlogo.cn/qqapp/{appid}/{openid}/100` 显示 C2C 联系人和群消息发送者头像
- 使用 SSE 将新消息实时推送到浏览器
- 本地持久化最近 20,000 条消息
- Secret 仅保存在服务端，配置读取接口不会返回 Secret

## 环境要求

- Node.js 22.18 或更高版本（使用 Node 原生 TypeScript 类型擦除）
- 可访问 QQ 官方机器人 API 和网关
- 已在 QQ 开放平台创建机器人并取得 AppID、App Secret 和所需事件权限

## 启动

```powershell
pnpm install
pnpm start
```

浏览器打开 <http://127.0.0.1:3210>，在设置中填写 AppID 和 App Secret，然后连接。

开发模式：

```powershell
pnpm dev
```

引用折叠和定位测试：

```powershell
pnpm test
```

连接生命周期和消息错误边界的独立回归测试：

```powershell
node --test tests/bot-lifecycle.test.ts
```

这些测试使用 fake Bot 执行服务端实际处理函数和信号监听器，不启动工作台或读取真实账号数据。
群聊和私聊消息处理失败时，仅记录账号 ID、消息 ID、事件类型和错误，不改变连接状态。
启动失败会清理实例；被取消的旧连接不能覆盖新的状态。停止失败会显示错误并保留实例供再次清理，
清理成功前不会创建替代连接。收到退出信号后，服务停止接受新操作、关闭 SSE 并等待已开始的清理与消息任务；
清理失败会记录错误并以非零状态退出。宿主不新增捕获全进程异常后继续运行的处理器。

浏览器回归脚本为 `tests/message-reference.browser.mjs`，需要可用的 Playwright。
可通过 `PLAYWRIGHT_MODULE` 指定其模块入口，运行 `node tests/message-reference.browser.mjs`；
脚本使用隔离测试数据，不连接 QQ，桌面和手机截图保存在 `data/test-results/reference/`。

SDK 引用解析测试在 SDK 源目录执行 `node --test scripts/reference.test.cjs`，先运行
`pnpm run build`。修改 SDK 后，将构建完成的 `lib/` 同步到 Web 的本地依赖构建目录，
并刷新已安装的 SDK 构建产物。
旧聊天记录如果没有保存引用快照，无法仅凭 `TMP_...` 恢复丢失的引用内容；
新的嵌套引用会保存完整快照。

## 内置 SDK

SDK 的唯一源码维护入口为仓库外层的 `sdk/qq-official-bot`。Web 通过
`file:./packages/qq-official-bot` 使用同步后的 `lib/` 构建产物；该依赖目录中保留的
`src/` 是历史快照，不作为 SDK 修改或重新构建的入口。SDK 修改后必须在源码目录
执行 `pnpm run build`，再同步产物并刷新已安装依赖。上游仓库及同步说明见该目录下的 `README.md`。
SDK 产物通过既有 GitHub 流程同步到 `packages/qq-official-bot/lib` 后，还需刷新 pnpm
安装的 `file:` 依赖并重启工作台，再验证实际加载的 SDK 版本。宿主边界测试使用 fake Bot，
同步后的 SDK 集成行为需单独验证。

监听地址在 `server.config.json` 中配置：

```json
{
  "host": "127.0.0.1",
  "port": 3210
}
```

修改配置后运行 `pnpm start` 即可生效。也可以临时使用环境变量覆盖配置文件：

```powershell
$env:WEB_QQ_HOST = '127.0.0.1'
$env:WEB_QQ_PORT = '3210'
pnpm start
```

## 数据与安全

- 多账号配置保存在 `data/accounts.json`，每个账号的消息保存在 `data/bots/{accountId}/messages.json`。
- 图片缓存保存在 `data/bots/{accountId}/media/`：收到的图片支持 JPEG、PNG、GIF 和 WebP、单文件最大 10 MB；成功发送的本地 PNG/JPG 也会进入缓存并在自己的消息中展示。每个 Bot 的图片缓存总计最大 1 GB，超限后自动删除最旧的缓存。
- 图片缓存下载超时为 15 秒；缓存失败时 Web 端会回退到 QQ 官方远程地址。视频和音频通过服务端流式下载，不保存到本地；下载连接或连续无数据超时为 30 秒，单文件最大 200 MB，仅接受公网 HTTPS 地址。普通文件仍使用原链接。
- 音频消息分别保存原文件的 `url` 与可选 WAV 副本的 `wavUrl`。旧记录若没有保存 WAV 地址，无法根据 AMR URL 恢复；不会把原文件改后缀冒充 WAV。在线播放使用官方 WAV 副本，共用下载模块的安全校验和流式传输；进度区间与接口说明见 [音频下载与播放接口](docs/audio-media.md)。
- 每条合并聊天记录最多自动缓存 20 张图片或动图；QQ 官方接口当前只支持接收合并消息，不支持主动发送。
- QQ 系统表情事件只包含表情 ID 和说明文字；Web 端使用内置 APNG/PNG 图片显示，遇到未知 ID 或资源加载失败时回退为文字说明。图片形式的表情包仍按普通图片缓存。
- 首次升级会把旧的 `data/config.json` 和 `data/messages.json` 复制到新结构，旧文件保留不删除。
- 从账号列表删除 Bot 时只移除配置入口，不删除对应的聊天记录文件。
- `data/` 已被 `.gitignore` 排除。
- 默认只监听 `127.0.0.1`。若改为局域网或公网地址，请先增加登录认证和 HTTPS，当前版本不应直接暴露到公网。
- 官方协议不会提供个人 QQ 的好友列表或既往聊天历史。会话只会在机器人收到消息后建立。
- 当前仅订阅 `GROUP_AND_C2C_EVENT`，不申请频道、子频道或频道私信权限。
- 主动消息、频率和消息类型由 QQ 官方机器人权限与平台规则决定。
- 发送媒体遵循 QQ 官方限制：图片支持 PNG/JPG（软限制 20 MB）、视频支持 MP4（软限制 30 MB）、语音支持 SILK（软限制 20 MB）、普通文件软限制 200 MB，所有类型硬限制均为 200 MB。本地文件超过软限制时 Web 端会提示确认，超过硬限制则拒绝上传；公网 URL 的文件大小由 QQ 平台在拉取时校验。只有成功发送的本地图片会保留缓存，文件、视频和语音发送后仍会清理。
- Bot 可撤回自己发送的消息；在群内拥有群主或管理员身份时，也可撤回普通群成员消息。群成员消息使用事件 `d.id` 调用撤回接口，不能撤回群主或管理员消息。
- 群成员禁言需要机器人拥有群管理员权限。
